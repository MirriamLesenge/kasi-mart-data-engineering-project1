**Platform:** Snowflake

## Project Overview

This project focuses on building and analysing a small relational dataset using **Snowflake and SQL**.

The project involves creating a Snowflake database and schema, creating tables with appropriate data types, loading CSV data, validating the loaded records, and performing SQL analysis on customer, product, and order data.

---

## Data Provided

The project consists of three CSV files containing customer, product, and order information.

| File            | Rows | Role      |
| --------------- | ---: | --------- |
| `customers.csv` |   50 | Dimension |
| `products.csv`  |   20 | Dimension |
| `orders.csv`    |  150 | Fact      |

The original CSV files were not edited.

### Customers

The `customers.csv` file contains customer information:

* Customer ID
* Customer name
* Email
* Province
* Signup date

### Products

The `products.csv` file contains product information:

* Product ID
* Product name
* Category
* Unit price

### Orders

The `orders.csv` file contains order information:

* Order ID
* Customer ID
* Product ID
* Order date
* Quantity

## Data Analysis

SQL was used to answer the four required business questions.

### 1. Order Details

The first query joins the orders, customers, and products tables to display information about every order.

It also calculates `line_revenue` by multiplying the quantity ordered by the product's unit price.

### 2. Revenue per Customer

The second query calculates the total revenue generated by each customer.

### 3. Revenue per Product Category

The third query calculates the total revenue generated by each product category.

### 4. Top 5 Customers

The fourth query identifies the five customers with the highest total spending.

All calculations and joins were performed directly in Snowflake.
